# Infra Guard

Ferramenta desenvolvida em Python para realizar verificações básicas de infraestrutura e segurança em sistemas Linux.

Funcionalidades

.Verificação do estado do serviço SSH.
.Verificação do estado do Firewall UFW.
.Identificação de serviços ativos ou inativos.
.Menu interativo para selecionar verificações.
.Execução de comandos Linux utilizando o módulo Subprocess.

Tecnologias

.Python 3
.Linux
.UFW
.Systemctl
.Subprocess

Execução: python3 infra_guard.py

Objetivo: Projeto prático desenvolvido para estudar automação com Python, administração Linux, monitoramento de serviços e fundamentos de segurança da informação.

Status: Atualmente parado.
